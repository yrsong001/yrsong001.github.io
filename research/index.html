OntoAnno: An Ontology-Grounded Agent for Reproducible Single-Cell Cell Type Annotation

OntoAnno is an open-source agentic framework for reproducible single-cell cell type annotation. It combines multi-resolution clustering, Cell Ontology-guided LLM reasoning, uncertainty scoring, hierarchical subclustering, retrieval-augmented evidence review, and automatic report generation through an interactive web interface.

The OntoAnno agent codebase is available on GitHub. The original GPTAnno R package remains available as a standalone backend for users who prefer a package-based workflow for ontology-guided annotation, resolution selection, and hierarchical subclustering.

Paper · OntoAnno agent GitHub · GPTAnno R package

Charting Postnatal Heart Development Using In Vivo Single-Cell Functional Genomics

Integration of 400k+ single-nucleus RNA-seq with Xenium spatial transcriptomics across postnatal time points to build a temporal-spatial atlas of mouse heart development. We map cellular niches, identify co-expression modules and gene maturation scores validated by ablation studies, and provide an interactive spatial atlas.

Paper (bioRxiv)

HR-VILAGE-3K3M: A Human Respiratory Viral Immunization Longitudinal Gene Expression Dataset for Systems Immunity

Largest multi-platform respiratory viral immunization dataset (14,136 profiles from 3,178 subjects across 66 studies). Curated for QC, batch correction, and vaccine response prediction. Released as an open-access resource on Hugging Face for method benchmarking.

Paper (arXiv) · Hugging Face

Decoding aging in the heart via single cell dual omics of non-cardiomyocytes

Single-cell RNA and ATAC of non-cardiomyocytes in the aging mouse heart to characterize transcriptomic and epigenomic diversity and cell-type-specific aging phenotypes. We infer gene regulatory networks and cell–cell communication and identify aging-responsive subclusters.
